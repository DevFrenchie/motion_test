# Motion Test

- Simple GameMaker Studio project that lives in `motion test.yyp`, the repo is already wired to build/export from GameMaker.
  
- `Room1` is the only room right now; it lays down a tiled background and instantiates a single object in the Instances layer.
  
- `player_obj` is a physics-enabled square (`Sprite1`) with a Step event that interpolates toward the mouse cursor while aligning its angle with the direction of travel.
